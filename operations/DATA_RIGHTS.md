# Permission register

Current catalogue: controlled synthetic products and retailers. Original SVG illustrations generated
as project source code. No external fashion photos, logos, retailer feeds or creator identities.
Reference uploads: browser-memory only; users are asked to use owned/permitted images. No AI or
third-party processing, persistence or public gallery is connected.

For a future source record: owner, agreement/version/date, permitted domains, display, resize,
cache TTL/location, embedding/inference/training rights separately, third-party processors,
attribution, removal/expiry, affiliate and creator-subnetwork conditions. Unknown means not allowed
until confirmed. Public API documentation does not establish licence to a retailer's assets.

Example offline rights file (sample-only):

```json
{"display":true,"reference":"controlled-test-only","allowedDomains":["example.com","example.org","example.net"]}
```

Do not repurpose the example as evidence of a real agreement. The importer checks structure and
an explicit permission declaration; it cannot independently verify that a licence is genuine.
