# No-spend constraint

Owner direction, 22 October 2026: nothing done for this project may cost money.

Continue local development, browser-based outfit generation, local storage and local tests.
Do not create cloud resources, deploy to hosting, purchase domains, start subscriptions, upgrade
plans, buy credits, create paid-service credentials or send metered AI requests. Do not assume a
free allowance prevents charges. Avoid remote CI runs when publishing source checkpoints.

Automatic provider recognition is disabled in application code under this policy, including when
API credentials happen to be present. Multi-photo manual marking and local outfit generation
remain available. Changing this policy requires the owner to explicitly change the spending
constraint; a key or model setting alone is not approval. No cloud project or deployment was
created during the 22 October setup inspection; only account/team/project lists were read.
